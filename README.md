# houseprice

Linear and Ridge regression written from scratch with NumPy, with a command-line
tool that trains on Excel (`.xlsx`) or CSV files, predicts on new files, runs
cross-validation and grid search, and writes Excel reports.

The `data/` folder contains a **synthetic** house-price dataset (fake values,
generated by `scripts/generate_data.py`).

## Install

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

Without installing, `PYTHONPATH=src python -m houseprice ...` works too.

## Usage

```bash
# Train on 80% of the rows, evaluate on the other 20%, save the model and a report
houseprice train data/houses.xlsx --target price --out model.json --report report.xlsx

# Predict prices for new houses (input and output can be .xlsx or .csv)
houseprice predict model.json data/new_houses.csv --out predictions.xlsx

# 5-fold cross-validation
houseprice cv data/houses.csv --target price --model ridge --alpha 10

# Grid search over Ridge alpha and polynomial degree
houseprice tune data/houses.csv --target price --alphas 0.1 1 10 --degrees 1 2 3 --out grid.xlsx
```

Useful options: `--features` to pick columns, `--sheet` to pick an Excel sheet,
`--model linear|ridge`, `--alpha`, `--degree`, `--method normal|gd` (exact
least squares or gradient descent), `--test-size`, `--seed`.

### What `train` prints

```
              R2          RMSE           MAE
train      0.901      54,306.5      36,410.9
test       0.924      55,342.9      39,016.4

Effect of +1 unit on price:
  surface_m2                       +1,671.18
  ...
  city=Paris                      +84,583.78
```

For a text column such as `city`, the first category in alphabetical order is
the reference: `city=Paris` is the price difference between Paris and that
reference city.

### The Excel report

| Sheet              | Content                                             |
| ------------------ | --------------------------------------------------- |
| `metrics`          | R2, RMSE and MAE on the train and test splits       |
| `coefficients`     | every coefficient, scaled and in original units     |
| `test_predictions` | test rows with the predicted value and the error    |

## Dataset

| Column               | Type  | Description                        |
| -------------------- | ----- | ---------------------------------- |
| `surface_m2`         | float | living area                        |
| `rooms`              | int   | number of rooms                    |
| `age_years`          | int   | age of the building                |
| `distance_center_km` | float | distance to the city center        |
| `city`               | text  | Paris, Lyon, Marseille or Lille    |
| `price`              | int   | sale price in euros (target)       |

Some cells are empty, as in real data. Regenerate everything with
`python scripts/generate_data.py`.

## Project layout

```
src/houseprice/
  data_io.py          read .xlsx/.csv tables, write Excel and CSV
  preprocessing.py    numeric/categorical detection, one-hot, polynomial terms, scaling
  models.py           LinearRegression and Ridge (normal equation or gradient descent)
  metrics.py          R2, RMSE, MAE
  pipeline.py         preprocessing + model, save/load as JSON
  model_selection.py  k-fold cross-validation, grid search
  report.py           Excel report
  cli.py              train / predict / cv / tune commands
tests/                pytest suite
scripts/              dataset generator
data/                 synthetic dataset
```
